# Deeds

Плагин [Obsidian](https://obsidian.md) для ведения протокола задач: переключение статусов с клавиатуры и цветная подсветка строк (выполненные и отменённые задачи — зачёркнутые) прямо в редакторе.

## Статусы задач

| Маркер   | Статус              | Оформление строки                  |
| -------- | ------------------- | ---------------------------------- |
| `- [ ] ` | не начата           | обычное                            |
| `- [✔] ` | выполнена           | зачёркнута, зелёный `#157a10`      |
| `- [✘] ` | отменена            | зачёркнута, красный `#870909`      |
| `- [✲] ` | частично выполнена  | жёлтый `#ad9c00` (без зачёркивания) |

Задачей считается вся строка — цветом и зачёркиванием оформляется текст всей строки, включая маркер статуса.

Задача — строка, *начинающаяся* с одного из префиксов выше (с завершающим пробелом). Отступ в начале строки не поддерживается. Нативный чекбокс Obsidian `- [x] ` задачей не считается.

## Хоткеи

| Команда                         | Хоткей      | Действие |
| ------------------------------- | ----------- | -------- |
| Toggle task on current line     | `Alt+Enter` | строка → задача (`- [ ] ` добавляется) или задача → обычный текст (префикс удаляется) |
| Set current task status to done     | `Alt+D` | переключить «выполнена» (повторное нажатие возвращает `- [ ] `) |
| Set current task status to cancelled | `Alt+C` | переключить «отменена» |
| Set current task status to partial  | `Alt+S` | переключить «частично выполнена» |

Команды работают с строкой курсора, доступны в палитре команд (это важно для мобильных) и переназначаются в настройках Obsidian: *Settings → Hotkeys → Deeds*.

## Режимы

- Live Preview и source mode — поддерживаются, подсветка строки цветом.
- Reading mode — не подсвечивается.
- Работает основной курсор; при Alt-Enter курсор остаётся на том же тексте (±6 символов).

## Важно: не используйте нативный чекбокс

Клик по чекбоксу или `Ctrl+L` создаёт маркер `- [x] `, который плагин **не распознаёт** — строка выпадает из всех функций (нельзя сменить статус, исчезает подсветка). Статусы меняйте только командами плагина (`Alt+D` / `Alt+C` / `Alt+S`). Если строка всё же стала `- [x] `, вернитесь через `Ctrl+Z` или уберите `x` вручную.

## Установка

1. Соберите плагин: `npm install && npm run build`.
2. В тестовое хранилище: скопируйте `manifest.json`, `main.js`, `styles.css` в `<vault>/.obsidian/plugins/deeds/` и включите плагин в *Settings → Community plugins*.

## Разработка

```bash
npm install    # зависимости
npm run dev    # esbuild watch
npm run build  # проверка типов + production-сборка main.js
npm test       # unit-тесты логики (node:test)
```
