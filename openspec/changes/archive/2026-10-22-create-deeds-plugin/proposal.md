# Proposal: create-deeds-plugin

## Why

В Obsidian нет штатного способа быстро вести протокол выполненных дел: переключать статусы задач с клавиатуры (не только «сделано/не сделано», но и «отменено», «частично») и визуально отличать исходы задач по цвету строки. Плагин Deeds закрывает это узким набором хоткеев и подсветкой.

## What Changes

- Создание нового плагина **Deeds** с нуля: каркас `manifest.json`, TypeScript + esbuild, `styles.css`.
- Команда **Alt-Enter**: строка без префикса задачи становится задачей (добавляется `- [ ] `); строка-задача становится обычным текстом (удаляются первые 6 символов).
- Команды переключения статуса текущей задачи (задача на строке с курсором):
  - **Alt-D** — «выполнена» `[✔]` (если уже `[✔]` → `[ ]`);
  - **Alt-C** — «отменена» `[✘]` (если уже `[✘]` → `[ ]`);
  - **Alt-S** — «частично выполнена» `[✲]` (если уже `[✲]` → `[ ]`).
- Подсветка в редакторе цветом **текста** всей строки: зелёный `#09ad00` для `[✔]`, красный `#ad0000` для `[✘]`, жёлтый `#ad9c00` для `[✲]`.

Осознанные ограничения v1: отступы в начале строки не поддерживаются (задача — строка, *начинающаяся* с префикса); `- [x] ` от нативного чекбокса Obsidian игнорируется (не задача); подсветка только в редакторе, режим чтения не затрагивается; работает только основной курсор.

## Capabilities

### New Capabilities

- `task-tracking`: распознавание строк-задач со статусами `[ ] [✔] [✘] [✲]`, превращение строки в задачу и обратно (Alt-Enter), переключение статусов с клавиатуры (Alt-D / Alt-C / Alt-S), подсветка строк в редакторе.

### Modified Capabilities

(нет — плагин создаётся с нуля)

## Impact

- Новый код плагина в корне репозитория: `main.ts`, декорации редактора, `styles.css`, `manifest.json`, конфигурация сборки (esbuild + TypeScript), `versions.json`.
- Зависимости: `obsidian` (API плагинов), dev-зависимости: esbuild, TypeScript, встроенный тестовый раннер Node для unit-тестов логики.
- Хоткеи регистрируются через `addCommand` (remap-ятся в настройках Obsidian; команды доступны в палитре — важно для мобильных).
